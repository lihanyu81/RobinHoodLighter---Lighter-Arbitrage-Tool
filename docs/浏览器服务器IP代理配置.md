# 浏览器使用服务器公网 IP 配置说明

本文用于将本地浏览器的 HTTP/HTTPS 请求通过 Linux 服务器转发，使网站看到的出口 IP 与服务器公网 IP 一致。

> 注意：这不是给套利程序配置 API 或交易账户的方法，而是给浏览器配置访问代理的方法。

## 一、准备工作

准备以下信息：

- 服务器公网 IP，例如 `203.0.113.10`
- 服务器登录账号和 SSH 权限
- 一个未被其他服务占用的 HTTP 代理端口，例如 `8080`
- 本地 Google Chrome 浏览器

先确认服务器架构和系统：

```bash
uname -m
cat /etc/os-release
```

## 二、安装 x-ui

### 2.1 进入 root 环境

正确命令是：

```bash
sudo -i
```

### 2.2 安装脚本

快速安装方式：

```bash
bash <(curl -Ls https://raw.githubusercontent.com/vaxilu/x-ui/master/install.sh)
```

该命令会下载并执行远程脚本。执行前如需审查脚本内容，可以先下载再查看：

```bash
curl -fL https://raw.githubusercontent.com/vaxilu/x-ui/master/install.sh \
  -o /tmp/x-ui-install.sh
less /tmp/x-ui-install.sh
bash /tmp/x-ui-install.sh
```

安装脚本来源：<https://github.com/vaxilu/x-ui>。

安装过程中如果脚本要求设置面板账号、密码和端口，建议立即设置强密码和非默认面板端口。不要长期使用 `admin/admin`。

检查服务状态：

```bash
systemctl status x-ui
```

如果服务未运行，可以执行：

```bash
x-ui start
```

## 三、登录 x-ui 面板

浏览器打开：

```text
http://服务器公网IP:54321
```

例如：

```text
http://203.0.113.10:54321
```

如果服务器防火墙或云厂商安全组拦截了 `54321`，需要临时放行该端口。建议只允许自己的公网 IP 访问，不要将管理端口开放给所有地址。

登录后立即完成以下操作：

1. 修改默认用户名和密码。
2. 修改面板端口。
3. 保存新的登录信息到安全位置。
4. 配置完成后收紧云服务器安全组，仅允许自己的 IP 访问管理端口。

当前安装脚本可能会在安装后要求修改账号、密码和面板端口，因此实际登录信息以安装过程中的设置为准，不要假定默认账号一定有效。

## 四、创建 HTTP 入站

登录 x-ui 后：

1. 进入“入站列表”。
2. 点击右上角的“+”。
3. 在“协议”中选择 `http`。
4. 设置一个代理端口，例如 `8080`。
5. 其他选项可以先保持默认；如果页面提供 HTTP 代理账号密码，建议启用认证并设置强密码。
6. 点击“添加”或“保存”。

注意：

- HTTP 入站端口是浏览器代理端口，不是 x-ui 面板端口 `54321`。
- 如果选择 `8080`，Proxy Omega 中填写的端口也必须是 `8080`。
- 不要把 HTTP 入站配置成任何人都能使用的开放代理。
- 云服务器安全组和系统防火墙应尽量只允许自己的公网 IP 访问该代理端口。

查看端口是否监听：

```bash
ss -lntp | grep -E ':54321|:8080'
```

如果使用其他代理端口，把上面的 `8080` 替换为实际端口。

## 五、配置 Chrome Proxy Omega

### 5.1 安装插件

在 Google Chrome 扩展商店中搜索并安装 Proxy Omega 或 Proxy SwitchyOmega。请确认插件来源可信，不要从不明网站下载扩展程序。

### 5.2 新建代理配置

打开插件设置，新建一个代理配置，例如：

```text
配置名称：RH-Lighter-Server
代理协议：HTTP
服务器地址：服务器公网IP
服务器端口：x-ui 中创建的 HTTP 入站端口
```

示例：

```text
配置名称：RH-Lighter-Server
代理协议：HTTP
服务器地址：203.0.113.10
服务器端口：8080
```

如果 x-ui 入站启用了认证，还需要填写对应的代理用户名和密码。

保存配置后，点击“应用设置”，再在插件菜单中切换到刚创建的配置。

## 六、验证浏览器出口 IP

在本地终端直接验证 HTTP 代理：

```bash
curl -x http://服务器公网IP:8080 https://ifconfig.me
```

如果代理启用了账号密码：

```bash
curl -x http://用户名:密码@服务器公网IP:8080 https://ifconfig.me
```

浏览器中也可以访问以下地址查看出口 IP：

- <https://ifconfig.me>
- <https://ipinfo.io/ip>
- <https://whatismyipaddress.com/>

如果显示服务器公网 IP，说明浏览器流量已经通过服务器转发。

## 七、与套利程序配合使用

配置成功后，浏览器访问服务器上的套利控制台时，可以通过该代理使网页请求使用服务器出口 IP。

套利程序本身仍然需要单独运行，代理配置不会替代以下内容：

- Lighter 和 RH Lighter API Key
- `RBLIGHTER_ACCOUNT_INDEX`
- Lighter / RH Lighter Market Index
- 外置 `.env` 配置
- 服务器上的套利程序进程

推荐的控制台访问方式仍然是 SSH 隧道：

```bash
ssh -L 8000:127.0.0.1:8000 用户名@服务器IP
```

只有在确实需要浏览器通过服务器公网 IP 出口时，再启用 Proxy Omega 代理。

## 八、安全注意事项

### 8.1 不要使用默认面板账号

安装完成后立即修改默认账号、密码和面板端口。不要把面板登录信息发到聊天软件或提交到 GitHub。

### 8.2 限制端口来源

建议：

- `54321` 面板端口只允许自己的公网 IP。
- HTTP 代理端口只允许自己的公网 IP。
- 关闭不需要的公网端口。
- 使用云厂商安全组和服务器防火墙双重限制。

### 8.3 不要创建开放代理

未认证的 HTTP 代理可能被第三方滥用，导致流量盗用、服务器 IP 被封禁或产生额外费用。建议启用代理认证，并限制来源 IP。

### 8.4 代理不是完整匿名方案

HTTP 代理只能改变部分 HTTP/HTTPS 请求的出口 IP。浏览器扩展、DNS、WebRTC、QUIC、其他应用程序或系统服务可能仍然使用本地网络。不要把“网页显示服务器 IP”理解为完整匿名或完整流量接管。

### 8.5 遵守平台规则

使用服务器代理必须符合所在地法律、云服务器服务条款、浏览器扩展规则以及相关交易平台的访问和 API 使用规定。不要使用代理规避平台的地区限制或安全策略。

## 九、故障排查

### 面板打不开

```bash
systemctl status x-ui
ss -lntp | grep ':54321'
```

同时检查云服务器安全组和系统防火墙是否放行面板端口。

### Proxy Omega 显示连接失败

依次检查：

1. x-ui 服务是否运行。
2. 入站协议是否为 `http`。
3. 代理服务器地址是否填写服务器公网 IP。
4. 代理端口是否填写 HTTP 入站端口，而不是 `54321`。
5. 代理账号密码是否正确。
6. 云安全组和系统防火墙是否允许访问代理端口。
7. 服务器是否监听在正确地址。

### 浏览器仍显示本地 IP

检查：

- Proxy Omega 是否已经切换到正确配置。
- 配置协议是否选择 `HTTP`。
- 服务器地址和端口是否有空格或填写错误。
- 浏览器是否被其他代理扩展或系统代理覆盖。
- 访问 `https://ifconfig.me` 时是否仍然显示本地 IP。

### 如何停止 x-ui

```bash
x-ui stop
```

查看 x-ui 日志：

```bash
x-ui log
```
